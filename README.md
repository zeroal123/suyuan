# 故障溯源

描述情况，找原因，看别人是不是也这样。

纯前端的单文件网页，没有服务器，不依赖 Claude。某个产品突然用不了、突然报错、突然变了的时候，写一句描述，它去查官方状态页和各个社区，告诉你最可能的原因、时间线、其他人的情况，以及现在能做什么。

## 用法

1. 打开页面，点右上角「设置」，填 DeepSeek API key，也可以再填一个 Gemini API key。key 只存在这台设备的浏览器里。
2. 点「连接自检」，确认各个来源可用。
3. 写一句情况描述，点「开始查」。

不填 key 也能用：只抓 GitHub、Hacker News 和官方状态页，做机械过滤，没有结论。

## 两家模型怎么分工

| | DeepSeek | Gemini |
|---|---|---|
| 拆解和归纳 | 可以 | 可以，有免费额度 |
| 联网搜索 | 可以，按次收费 | 不接（免费档的新模型不带搜索） |
| 国内直连 | 可以 | 需要梯子 |

在「设置」里选用哪家做拆解和归纳。两家的 key 都填时，选中的那家调用失败会自动换另一家，并在结果里说明。只填 Gemini key 时没有联网搜索，证据只来自 GitHub、Hacker News 和官方状态页。

## 流程

1. **拆解**：把描述拆成产品、症状、报错原文。有 key 用模型，没 key 用内置词表。
2. **搜索**：十余条细分查询并行，分别对着综合、Reddit、X、报错原文、官方通告、官方变更、中文社区、上游故障；另外直接读 GitHub issues、Hacker News、官方状态页。
3. **机械去重过滤**：同一链接合并，超出时间范围的去掉，没提到产品或症状的去掉，聚合站只留 2 条当热度信号，相似标题归组，同一网站最多 12 条，总数最多 40 条。
4. **语义筛选与归纳**：模型逐条判断是不是同一件事、是不是在转述别的条目，再给出带证据编号的结论。
5. **代码校验**：证据编号必须存在；没有官方依据且独立来源不足时，自动下调把握程度。

被排除的条目都带原因，在页面底部可以点开核对。

## 时间范围怎么算

| 条目 | 留多久 |
|---|---|
| 社区帖子、新闻、聚合站 | 你选的时间范围 |
| 官方状态页上的事故 | 时间范围和 7 天里较长的那个 |
| 官方公告、更新日志 | 时间范围和 30 天里较长的那个，最多 5 条 |

政策、限额这类变更常常是几周前公告、最近才生效，所以官方公告放得更宽。靠放宽才留下的条目会标「早于时间范围，仅作背景」。结论开头的「最近的情况」只写时间范围之内发生的事，并标出问题现在是仍在持续还是已恢复。

## 国内产品模式

微信、B 站、学习通这类国内产品一般没有公开状态页，线索在微博、知乎、贴吧和新闻里的企业回应中。页面识别出国内产品后会自动换一套：

- 查询换成微博、知乎、贴吧、小红书、B 站、企业回应和国内云厂商故障，不再查 Reddit、X、GitHub、Hacker News。
- 直达链接换成微博搜索、知乎、贴吧、小红书、B 站、百度资讯。
- 国内平台的帖子可能被删、热搜可能被撤，所以搜到的讨论少时结论只会是「证据不足」，不会判成「多半是你这边的问题」。
- 识别靠内置名单和模型判断，判错了可以在「手动指定」里改产品类型。
- 这个模式完全依赖联网搜索，没填 DeepSeek key 时只有直达链接可用。

## 代码校验

模型给出的结论不会原样显示，代码会先核对并修正，修正过的地方列在结论卡的「代码校验修正了 N 处」里：

- 证据编号必须存在；没有官方依据且独立来源不足时下调把握程度。
- 说是「官方主动变更」必须引用官方条目，说是「上游故障」必须引用上游事件的条目，否则下调并标注。
- 结论类型要和原因对得上，比如判成「本地问题」却引用了官方确认的服务方故障，会改成「部分人受影响」。
- 时间线按时间先后重新排序。

## 补充材料（可选）

Reddit、X 和群聊的内容页面抓不到。结果页里有一个默认折叠的「补充材料」：把你自己看到的帖子或聊天记录粘贴进去，模型会把它拆成带时间的条目，并入证据后重新归纳，不重新搜索。

- 不用它，主流程和结论不受任何影响。
- 粘贴的条目会标出「你粘贴的」，超出时间范围的照样会被排除。
- 不想看到这一块，在「设置」里关掉。

## 来源与限制

| 来源 | 方式 | 限制 |
|---|---|---|
| DeepSeek Search | 接口 | 要 key；Reddit、X 的内容靠搜索引擎收录，新帖有延迟 |
| GitHub issues | 接口 | 未登录每分钟 10 次搜索 |
| Hacker News | 接口 | 无 |
| 官方状态页 | Statuspage v2 接口 | 只支持这种格式的状态页，其余只给跳转 |
| Reddit、X、Downdetector | 一键直达 | 不允许页面抓取，只能跳过去看 |

群聊里的消息搜不到。

如果自检显示 DeepSeek 接口被跨域策略拦截，可以在「设置」里把接口地址换成自己的转发地址。

模型不写死：「设置」里两家的模型列表都从你的账号读取，出了新模型点「刷新列表」就有，也可以手动填任意模型名。旧模型下线时，查询会提示换模型。

## 开发

源码在 `src/`，`index.html` 是构建产物，不要直接改。

```bash
python3 build.py              # 生成 index.html
node --test test/core.test.js # 纯逻辑单元测试
node test/e2e.mjs             # 端到端测试，需要 Playwright；所有网络请求都被拦截成假数据
```

不要把 API key 写进仓库。
